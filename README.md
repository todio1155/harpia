# HARPIA NINHO: introdução

Projeto "Harpia Ninho" é uma impressora 3D projetada para ser open-source (leia a licença atual do projeto antes de usar), durável, modificável e atualmente ficando mais fácil de consertar e fazer módulos de expansão, tipo um LAN/Ethernet, mais NTC, driver de passo, FRAM e muito mais. Ele foi feito para ATX-20 ou ATX-24; licença "CERN-OHL-S-2.0".
## contexto
Eu queria uma impressora 3D barata, eficiente, personalizada e open-source que pudesse ser muito modificada. 

## pré requisitos
[kicad 10.0 ou maior](https://www.kicad.org/download/)
