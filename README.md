Projeto "Harpia Ninho" é uma impressora 3D projetada para ser open-source (leia a licença atual do projeto antes de usar), durável, modificável e atualmente ficando mais fácil de consertar e fazer módulos de expansão, tipo um LAN/Ethernet, mais NTC, driver de passo, FRAM e muito mais. Ele foi feito para ATX-20 ou ATX-24; futuramente vai ter versão 24V. "CERN-OHL-S-2.0"
